forward, reverse, from 2026-11-27 01:36:12 to 01:36:25 UTC. The

`cc483dbc8bfc08fa95bf016a16c9b9f86a461e492358af95839e4178149aab41`.

`402828098781ef2330fd775abedee6784290fcbe8e089cc04b45f37b92774955`.
Each process executed 96 points, three warmups and 15 timed samples
per point. Raw occurrence order, geometry keys, transfer lengths
and frozen steps agree. All three host gates passed, with peak
aggregate busy shares of 5.66%, 5.77% and 5.54%, respectively.

Direct comparison with the original frozen binary under
`cuobjdump -sass -arch sm_121` found identical instructions in all
ten MLP and flush symbols. Both replay orders call the same compute
kernels as the original path. Sample start and launch completion
are host monotonic observations. The flush-completion timestamp is
estimated from the launch endpoint and same-stream events with the

## Registered GB10 exception

The approved unresolved branch registers low-in-flight instability
for GB10 only. It applies to the following fields and point keys
in a future qualified full-profile capture.

| Field | Points |
| --- | --- |
| `dram_bw_by_bytes_in_flight` | Cold-read points at or below 256 KiB total in flight, both issue paths |
| `dram_bw_by_bytes_in_flight_strided` | Cold-read points at or below 256 KiB total in flight |
| `dram_bw_by_active_sms` | Target 1 or 2 SMs |

Keep every sample and all process medians. At these points record
the min and max of the process medians, set `rel_uncertainty` to
cover the observed spread including both clusters, and tag the
point `low_in_flight_unstable`. Exclude these points from the
cohort decision for rules 1 and 3. Rule 2 still applies to every
point, and all three rules remain in effect outside the exception.
The earlier host-gated archive already failed rule 2 for DRAM
active-SM. This registration does not qualify that batch or replace
any installed profile measurement. The affected range includes
low-CTA, latency-limited decode geometries.
