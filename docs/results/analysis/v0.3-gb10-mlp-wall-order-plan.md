# Wall-clock replay and order reversal for GB10 MLP

Post-hoc protocol for review before capture. Run exactly three
independent full `mlp` sweeps in order: forward, forward, reverse.
Each sweep contains the same 96 geometry keys (48 cold DRAM and
48 warm L2), with three warmups and 15 timed samples per point.
Reverse the whole sequence, including the memory-level and issue-mode
boundaries. The forward and reverse step files bind each key to its
original frozen step count and transfer geometry. Keep the source
allocations, issue widths and read-only cold flush.

Record a `CLOCK_MONOTONIC` origin at executable entry. For each timed
sample record the host time at sample start, observed flush completion
(cold points), and observed launch completion, plus CUDA event duration.
Record SM frequency immediately before and after each point and retain
its clock-probe duration. Use identical instrumentation in all three
runs. Document any synchronization required to observe flush completion
and its impact on the time between flush and launch. Verify the SASS of
each timed kernel's hot loop instruction by instruction against the
unmodified kernel built with the same toolchain and flags. A hot-loop
mismatch invalidates the comparison.

Take the shared Spark 1 lock for all CUDA calls and use the integrated
host-quiet and thermal gates. Before timing, bind the binary, toolchain,
geometry manifest, schedules, clock method and SASS comparison by
digest. After each process verify all 96 point keys in execution order,
their lengths, timestamps, and at least 1 ms per timed launch. Preserve
failed receipts. The forward pair must reproduce slow segments before
the reversed run can distinguish the hypotheses.

## Prespecified interpretation

Keep the archived marker (bandwidth strictly below 85% of the point's
within-run maximum) and segments of at least two consecutive marked
samples. The onset is the first marked sample's host start relative
to the executable origin. Compare all matched and unmatched onsets.

- **Time effect.** The two forward onsets and an onset at a different
  point in reverse agree within 20 ms. Compare each pair of the three
  times. The protocol candidate disperses each point's samples across
  interleaved sweeps.
- **Point or predecessor effect.** The reverse sweep reproduces the
  same geometry key as the two forward sweeps at a different time
  (over 20 ms from each forward onset). The protocol candidate changes
  the order or inserts an inter-point gap.
- **Unresolved.** Conflicting or insufficient matches, or a failed
  forward reproduction, support neither protocol change on this test.
  Report the evidence and use the separately approved exception
  procedure.

for every receipt. This comparison supplies diagnostic evidence for
